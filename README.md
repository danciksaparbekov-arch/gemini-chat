# Gemini Chat

Простой веб-чат с моделями Google Gemini: выбор модели из списка, отправка текста и скриншотов.

**Сайт:** https://danciksaparbekov-arch.github.io/gemini-chat/

## Как пользоваться
1. Получите бесплатный ключ: <https://aistudio.google.com/apikey>.
2. Нажмите «🔑 Ключ» и вставьте его.
3. Выберите модель (список берётся у Google по вашему ключу), пишите сообщения.
4. Скриншоты: `Ctrl+V`, перетаскивание в окно или кнопка 📎 (до 6 за раз; крупные уменьшаются до 1600 px).

В списке показываются только модели с бесплатным уровнем (Flash, Flash-Lite, Gemma, Hydrogen). Google не отдаёт цену через API, поэтому фильтр работает по имени модели (`isFree` в `app.js`); актуальные условия: <https://ai.google.dev/gemini-api/docs/pricing>.

## Режим «3ds Max»
Селектор «3ds Max / Общий» в шапке. В режиме 3ds Max модель получает:
- **системный промпт** — [prompts/3dsmax.md](prompts/3dsmax.md) (роль, версия программы, правила ответа);
- **фрагменты базы знаний** — папка [kb/](kb/): перед каждым вопросом чат подбирает до 4 подходящих разделов (`## ...`) по ключевым словам и добавляет их в запрос;
- переключатель **🔍 Поиск** — Google Search grounding: модель ищет в сети и показывает источники (зависит от модели и лимитов бесплатного уровня).

Как пополнять базу: скопируйте `kb/_template.md`, заполните (один раздел `##` = одна законченная мысль), добавьте файл в `kb/index.json`. Не копируйте документацию Autodesk целиком — защищена авторским правом; пишите свои конспекты.

## Безопасность
- Бэкенда нет: страница общается напрямую с `generativelanguage.googleapis.com`.
- Ключ хранится только в `localStorage` браузера (или `sessionStorage`, если снять «Запомнить») и никуда, кроме Google, не отправляется.
- Весь вывод модели экранируется перед показом, HTML не исполняется.
- При подозрении на утечку отзовите ключ в AI Studio.

## Запуск локально
```bash
python -m http.server 8000
```
