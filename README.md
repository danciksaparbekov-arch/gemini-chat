# Gemini Chat

Простой веб-чат с моделями Google Gemini: выбор модели из списка, отправка текста и скриншотов.

**Сайт:** https://danciksaparbekov-arch.github.io/gemini-chat/

## Как пользоваться
1. Получите бесплатный ключ: <https://aistudio.google.com/apikey>.
2. Нажмите «🔑 Ключ» и вставьте его.
3. Выберите модель (список берётся у Google по вашему ключу), пишите сообщения.
4. Скриншоты: `Ctrl+V`, перетаскивание в окно или кнопка 📎 (до 6 за раз; крупные уменьшаются до 1600 px).

## Безопасность
- Бэкенда нет: страница общается напрямую с `generativelanguage.googleapis.com`.
- Ключ хранится только в `localStorage` браузера (или `sessionStorage`, если снять «Запомнить») и никуда, кроме Google, не отправляется.
- Весь вывод модели экранируется перед показом, HTML не исполняется.
- При подозрении на утечку отзовите ключ в AI Studio.

## Запуск локально
```bash
python -m http.server 8000
```
