# Базовые горячие клавиши и навигация

> Стартовый набор классических клавиш по умолчанию. Если у пользователя раскладка изменена (Customize → Customize User Interface → Keyboard), клавиши могут отличаться.

## Инструменты трансформации
- Q — Select (выделение), W — Select and Move (перемещение), E — Select and Rotate (поворот), R — Select and Scale (масштаб).
- H — выделение по списку (Select From Scene), Ctrl+A — выделить всё, Ctrl+D — снять выделение.
- Ctrl+Z — отменить, Ctrl+Y — повторить.

## Навигация в окне просмотра (viewport)
- Alt + средняя кнопка мыши — вращение (орбита), средняя кнопка — панорама, колесо — масштаб.
- Alt+W — развернуть активное окно на весь экран и вернуть обратно.
- P — Perspective, T — Top, F — Front, L — Left, B — Bottom, C — Camera, U — User (ортографический вид).

## Отображение
- F3 — переключение каркас (Wireframe) и закрашенный вид (Shaded).
- F4 — показать рёбра поверх закраски (Edged Faces).
- Alt+Q — изолировать выделенное (Isolate Selection), повторное нажатие возвращает сцену.
- G — показать или скрыть сетку (Grid).

## Подобъекты Editable Poly / Edit Poly
- 1 — Vertex (вершины), 2 — Edge (рёбра), 3 — Border (границы), 4 — Polygon (полигоны), 5 — Element (элементы).

## Привязки
- S — включить или выключить Snaps (привязки).

## Материалы и рендер
- M — редактор материалов (Material Editor).
- F10 — окно Render Setup, F9 — повторить последний рендер, Shift+Q — быстрый рендер (Quick Render).

## Поиск команд
- X — окно поиска команд (Search Commands), удобно, когда не помнишь, где пункт меню.
